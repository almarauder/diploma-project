# Tort Tulik — Frontend application

Open `index.html` in a browser (needs internet for the Tailwind, Inter font and Lucide CDNs).

    frontend-application
    ├── pages/        DashboardPage, NotificationsPage, AnimalsPage, ScanPage, AiAgentPage, ProfilePage
    ├── components/   Sidebar, Header, GreetingBanner, FarmSummaryCard, StatusCards, ScheduleTasks,
    │                 HerdInspectionBanner, SyncNote, NotificationFilters, NotificationList, MobileNav, Modal
    ├── routing/      routes.js (route table), router.js (switchRoute + app start)
    ├── layouts/      AppLayout.js (sidebar + header + page container + mobile nav + modal)
    ├── assets/       logo.svg (favicon)
    └── styles/       tailwind.config.js (brand theme), main.css (font, background, scrollbar)
